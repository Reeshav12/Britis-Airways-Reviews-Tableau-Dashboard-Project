# ✈️ British Airways Reviews — Tableau Dashboard Project

An end-to-end **Tableau data analytics project** demonstrating real-world dashboard design, data modeling, and interactive visualization using airline customer review data.

This project showcases how professional data analysts build interactive dashboards used for business insights and decision-making.

---

## 📊 Project Overview

This project analyzes **British Airways customer reviews** and builds a fully interactive Tableau dashboard where users can:

- Switch between rating metrics with one click  
- Filter by aircraft, traveler type, continent, and date  
- Explore trends over time  
- Compare aircraft performance  
- Analyze global customer satisfaction  

The goal is to create a **portfolio-ready Tableau dashboard** similar to what companies expect from data analysts.

---

## 🎯 Objectives

- Build a professional Tableau dashboard  
- Practice data relationships & modeling  
- Use parameters and calculated fields  
- Design interactive filters  
- Create clean UI/UX dashboard layout  
- Publish to Tableau Public  

---

## 📂 Dataset

This project uses two CSV files.

### 1️⃣ ba_reviews.csv
Each row represents a customer review.

Columns include:
- Country (place)
- Date
- Overall Rating
- Seat Comfort
- Cabin Staff Service
- Food
- Entertainment
- Ground Service
- Aircraft
- Seat Type
- Traveler Type

### 2️⃣ countries.csv
Used for mapping and regional analysis.

Columns:
- Country  
- Continent  
- Region  

---

## 🔗 Data Modeling

Relationship created between:

ba_reviews.place → countries.country

This enables continent filtering and geographic analysis.

---

## 🗺️ Dashboard Features

### Interactive Map
Parameter lets users switch metrics.

### Filters
- Date  
- Seat Type  
- Traveler Type  
- Aircraft  
- Continent  

### KPI Summary
Average ratings across categories.

### Trend Chart
Metric trends over time.

### Aircraft Analysis
Average rating per aircraft with review counts.
